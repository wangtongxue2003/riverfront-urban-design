# 发布整理检查记录

日期：2026-11-19。此文件说明修复范围与验证边界，不代表原项目的全部设计指标已获得严格验证。原始工程保持不变，改动仅发生在发布副本。

## 已实施的修复

| 类别 | 处理 |
| --- | --- |
| Maven 构建 | 去掉工程自身依赖、重复/混合版本依赖；jMetal 统一为 6.6；旧 `getResult()` 调整为兼容接口 `result()`；清理无用 import |
| 依赖体积 | 原资源目录 35 个 JAR 精简为 `lib/` 中 12 个必要历史构建；可公开解析的依赖改由 Maven 获取 |
| 独立入口 | 新增 `examples.SyntheticCourtyardDemo`，无需原场地数据，默认构造六个院落并使用真实门窗模板 |
| 文件兼容 | 新默认入口和历史流程的 .3dm 写出显式使用 Rhino 4 格式，检查写出结果；规避旧 iGeo 默认写出/回读不兼容 |
| 路网 | 用 JTS 节点化连接内部交点；按线性里程切线；修复 Graph 带参构造；统一二维坐标键，使用 Dijkstra |
| 基础几何 | 修复斜向脊线的垂线、Vec 新向量减法、Plots 数组构造漏掉首变量；Site 为二维坐标补 z=0，避免 NaN 几何 |
| 建筑面积 | B101 改为两段各 35% 的占地系数；RecTypeB 累加子地块面积，并稳定复用选型；B1/B10/B10XY 单栋模式不在绘图时改变层数字段 |
| 优化配置 | 南岸从单候选单评价改为可配置预算；修复非负惩罚作为约束的符号，并启用含约束的支配比较器；暴露随机种子等设置 |
| 结果对应 | 南北岸按稳定顺序串行生成模型并导出 `solution_id`，CSV 列名对应实际指标；关闭评价线程池 |
| 门窗与输出 | 移除每次绘门时删除共享模板的行为；更新场景生成改为串行；输入、准备模型和结果路径分离，缺文件时给出提示 |

`Zshare` 原作者署名保留，对它的修改主要是本次依赖版本所需的 API 兼容调整，不把其原算法归为本项目原创。

## 验证结果

在 Windows x64 / JDK 23.0.1 / Maven Wrapper 3.9.9 下运行完整 `clean verify`：**10 tests，0 failures，0 errors，0 skipped**。

- 六个合成院落生成 1,428 个对象、1,404 个曲面；真实门窗模板读取成功。
- 导出 `.3dm` 后重新读取，断言曲面存在、门构件图层和第六院落保留。
- 无效尺寸及不支持的层数模式被拒绝。
- 十字相交、T 型连接、断网和沿线插点的距离回归通过。
- 斜向垂线、向量减法、B101 面积、多地块面积累加与重复评价稳定性通过。
- 单栋类型绘图前后面积不变，所生成曲面有效；不再产生测试中原先观察到的 NaN 控制点错误。

## 尚未验证或仍需研究的内容

- 未使用私有场地数据重跑完整南岸、北岸及更新优化；原成果 GIF 仅用于历史展示。
- 大部分类型的面积仍为规则公式，尤其组合类型与混合层数尚未统一为逐栋几何核算；不能据此声称所有面积指标已完全准确。
- 未证明多目标搜索收敛，也未证明内接矩形为全局最优。
- 任意凹地块、复杂 NURBS、孔洞、退化 Voronoi、重合种子等情况仍需专门测试。
- 旧可视化和 ArchiJSON 实验保留源码并参与编译，但不是默认运行路径。
- 第三方库的许可证与项目提供者已有授权需维护者确认，参见根目录来源说明。
